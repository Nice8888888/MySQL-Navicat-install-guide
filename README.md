# Windows 11 安装 MySQL 与 Navicat：过程记录

这篇文章记录我在 Windows 11（Intel处理器） 上安装 MySQL 和 Navicat、
配置本地数据库连接的过程，以及安装过程中遇到的问题。

## 一、电脑环境

- 操作系统：Windows 11
- 处理器：Intel 第 13 代 Core i7
- MySQL 版本：待安装完成后填写
- Navicat 版本：Navicat Premium 18
- Navicat 授权：学生非商业订阅

如果你是在校学生或者是老师，可以申请Navicat官方主页的“Navicat学术伙伴计划”，免费使用指定时间、指定版本的Navicat官方软件。如果是学生的话，可以先填写官网的资料，记得最好使用学校邮箱，便于后续审核。填写完毕后，邮箱会受到官方邮件，要求你填写指定表格并且提供学信网含二维码的在读证明。按要求发过去之后大概一天就会审核通过，告知你如何激活Navicat订阅，会给出详细网址和步骤。

### 2. 下载 Navicat

你可以按照邮件里面的网址自由选择需要的版本进行安装，这里我使用的是
Navicat Premium - Non-Commercial Simplified Chinese Edition，网址为
https://www.navicat.com.cn/download/navicat-premium，直接点击就可以打开对应的下载界面。里面会显示三个下载位置，位置1和位置2是同一产品的不同下载入口，第一个下载慢或失败时换第二个。我是用了VPN，所以下载的还比较快。下载完毕后，你可以直接安装。首先会出现一个安装须知，这个必须选同意，否则无法继续进行。后面安装位置选择一个合适的位置就行。创建桌面快捷操作创建或者不创建都可以。安装基本就结束了。
